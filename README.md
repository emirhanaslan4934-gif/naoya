# Naoya (Fabric 1.21.11)

Build:  ./gradlew build   (needs JDK 21; add the Gradle wrapper with `gradle wrapper` if missing)
Output: build/libs/naoya-1.0.0.jar  -> put into .minecraft/mods together with Fabric API

Use: press Right Shift in game to open the GUI. Drag the purple header to move it.
- Fly:  toggle + speed buttons
- Xray: shows ores only, plus fullbright. Does not work together with Sodium.

Version numbers in gradle.properties: verify at https://fabricmc.net/develop
